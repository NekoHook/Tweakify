## About

**Tweakify** is an open-source project aiming to build a modern package management experience for jailbroken iOS devices.

The goal is to provide a clean, intuitive, and transparent way to discover, manage, and install jailbreak tweaks — with an emphasis on usability, compatibility, and community-driven development.

Tweakify is intended to become an alternative to existing package managers such as Sileo.

**The project is under active development.** Installation, compatibility, and release information will be documented as these capabilities become available.

## Vision

- **Package discovery** — browse and search for jailbreak tweaks.
- **Repository management** — manage package sources in one place.
- **Package details** — inspect descriptions, versions, dependencies, and compatibility.
- **Package management** — install, update, and remove packages.
- **Open source** — inspect the code, report issues, and contribute improvements.
- **Community driven** — build a better jailbreak experience together.

These are project goals, not a claim that every feature is already implemented.

## Compatibility

Tweakify's target environments and supported iOS versions have not yet been finalized.

Compatibility claims will be published after they have been implemented and tested.

## Roadmap

The initial development priorities are:

1. Establish the project architecture.
2. Build the package browsing interface.
3. Implement repository and package metadata handling.
4. Integrate package installation and dependency management.
5. Test compatibility across supported jailbreak environments.
6. Prepare documentation and an initial release.

The roadmap is subject to change as development progresses.
