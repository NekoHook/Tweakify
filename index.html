A package manager, taken from the drawing board.

What Tweakify is meant to do — stated as goals, not as shipping features. The labels say exactly where each one stands today.

01 Planned

Package discovery

Find and explore jailbreak tweaks — browse, search and filter, with the details that matter surfaced up front.

02 Planned

Repository management

Add, organize and refresh package sources. Repos are first-class citizens, not an afterthought.

03 Planned

Package details

Inspect versions, descriptions, dependencies and compatibility before anything touches your device.

04 In development

Open source

Every line is public from day one. Inspect the code, question it, improve it — the repository is the source of truth.

05 Vision

Compatibility first

Designed around the realities of jailbroken iOS — environments, iOS versions and what actually works together.

06 Vision

Community driven

Development happens in public. Issues, pull requests and discussion decide what Tweakify becomes.

02

Under active development.

Tweakify is being built in the open. Today the project is its foundation: the source code, this website and the plan — all public, all early. There is nothing to install yet, and this page won't pretend otherwise.

What exists is easy to check: read the source, watch the repository and see every decision as it lands. The gap between the vision and the current state is part of the project — it is exactly what development is for.
